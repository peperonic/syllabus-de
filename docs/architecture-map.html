The eleven MCP tools

The nine tools from the brief, plus get_node and neighbors from the package's CLAUDE.md. Select a tool to light up the tables it reads in the map above. Most tools take the same context: {"land": "MV", "school_form": "Gymnasium", "grade": 8, "subject": "Mathematik", "course_level": null, "date": "2026-11-07"}. Every response states the curriculum version and the evaluation date, lists its node ids under citations, and carries a 2 to 4 sentence summary_de.

The exercise loop

The order the exercise-writer's system prompt enforces. Highlighted steps are the model's own work; the rest are MCP calls.

2curriculum_status

3exercise_brief

Goal, allowed concepts, operators, AFB mix.

4write the Aufgabe

Inside the frame from the brief.

5check_exercise

Findings with pass, warn, fail.

6deliver

Metadata cites document version and evaluation date.

fail any fail in step 5 sends the draft back to step 4; warn findings are reported with the exercise.

Which plan applies

Validity in time is a first-class property. Real case from the inventory: MV Rahmenplan Mathematik Sekundarbereich I Gymnasium 2026 is upcoming, "2027/28 aufwachsend (gültig ab 01.08.2027)", grades 7 to 10. Its predecessor, Rahmenplan Mathematik 7-10 (AHR), is "gültig bis 31.07.2031, auslaufend".

school year  y = year(d) if month(d) ≥ 8, else year(d) − 1
rollout = ascending_from_grade:N, first year Y0
new plan binds ⇔ y ≥ Y0 and g ≤ N + (y − Y0)
otherwise follow the supersedes edge back to the old plan
2026 plan bindsold AHR plan binds

The grid shows the old plan is no longer needed for grades 7 to 10 after 31.07.2030, one year before its stated end. One plausible reason is repeaters. S0b now reads both entries from the real inventory: the 2026 plan as ascending_from_grade:7 from 01.08.2027 (inferred), the AHR plan with end 31.07.2031 and unknown start (needs review), and links them with a supersedes edge.

Before, current, not yet

Plans give grade bands (5/6, 7/8, Einführungsphase, Q1 to Q4). Bands are kept as intervals [a, b] on each node. For pupil grade g, within the binding documents of the same Land and track:

taught_before
b < g
prerequisites the pupil should know, grouped by band
current
a ≤ g ≤ b
with verbatim text, node id, page
not_yet
a > g
avoid in exercises; reports the grade where it appears

If a < b and the plan leaves the order inside the band to the school, the topic stays in current, and uncertainty says that the pupil may or may not have met it yet. The half-year is never invented. Bayern LehrplanPLUS gives single grades, so its bands collapse to a = b.

Certify or decline

S5 proposerLLM proposes maps_to (node to topic) and requires (topic to topic) with confidence.
mechanicalNode id exists; subject of node equals subject of topic; grade span overlaps the topic's band (warn only).
judgeA model from a different family reads the verbatim text and audits each edge independently.
verdictcertified = 1declined, audit row kept
gold setHuman-verified mappings that the proposer and judge never see. They measure precision and recall of the edges that are certified.

What M0 has established

Results from the offline tests and from running S0 and S0b over the real inventory. No curriculum text has been fetched yet.

A cohort changes plan at most once

Along a cohort g − y is constant, so g ≤ N + (y − Y0) holds for every year of that cohort or none. The other condition, y ≥ Y0, does not. So a cohort switches only in Y0, and exactly the cohorts in grades a < g ≤ N then: N − a cohorts.

A property test disproved my first, stronger claim (no switching ever) on BW-style "Klassen 1 und 2" rollouts. For the switching cohorts, curriculum_status now names what the new plan assumes from earlier grades that the old plan never taught.

Schema additions, built

The draft schema.sql could not answer every field the brief asks for. These additions are now in design/schema.sql, which the code loads directly.

documentadd doc_slug, rollout (all_grades | ascending_from_grade:N), school_year_start (default 08-01), validity_note for raw text and mismatches.
school_form_aliasLand, alias, official name. Feeds the normalisation that resolve_context returns.
pathwayWhich school form a pupil on a track attends at each grade (MV: Grundschule 1 to 4, Orientierungsstufe 5 to 6).
document_school_formThe inventory's composite strings split into official school forms.
conventionLand, subject, school form, band, kind (notation, units, Merkhilfe, calculator WTR or CAS), text, source node or evidence id.
competenceadd land and subject so Land operator lists sit next to the KMK Anforderungsbereiche I to III.
node_vecnot built: optional embeddings for topics_for. The server works with FTS5 alone.

Decisions taken from the brief

  1. Scope: curricula of all 16 Länder for Mathematik, Chemie, Physik, Biologie, Politik/Wirtschaft, Arbeitslehre/WAT, integrated science and social-studies courses, Sachunterricht; all general-education school forms; no berufliche Schulen or Förderschulen.
  2. Format: SQLite knowledge graph with FTS5 (design/schema.sql), not Markdown files. Python for builder, API and MCP server.
  3. Sources: the inventory only. Raw downloads cached by sha256 outside git; full text only where the licence policy allows it.
  4. Language: curriculum text verbatim in German, code and keys in English, summary_de in German, no em dashes in generated text.
  5. Conventions: the package's CLAUDE.md rules govern the repo; commits go straight to main and are pushed after every step.
  6. First slice: MV Mathematik (8 documents, including the 2026 plans in transition) through S6, shown to you before widening.
  7. Models: proposer claude-sonnet-4-6, judge claude-opus-5-5. Same vendor, so independence comes from separation: the judge never sees the proposer's reasoning, and the gold set measures the result.
